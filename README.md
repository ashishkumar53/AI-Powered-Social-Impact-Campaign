# AI-Powered Social Impact Campaign – Digital Detox Week

## Project Overview

The **AI-Powered Social Impact Campaign** is a campaign project focused on promoting Digital Detox Week among students.

The project demonstrates how AI-powered audience research, campaign messaging, visual storytelling, and workflow automation can work together to create a structured social impact campaign.

## Project Objectives

- Understand student digital habits and challenges.
- Develop campaign messaging to encourage healthier digital habits.
- Create a visual narrative showing the journey from digital distraction to focused study and mindful living.
- Use n8n to build a workflow automation component for the campaign.

## Project Components

### 1. Audience Research and Campaign Messaging

Explored student-related digital distractions and developed campaign messaging around digital wellbeing, mindful technology use, and focused learning.

### 2. Visual AI Storytelling

Created a six-scene visual campaign narrative:

| Scene | Theme |
|---|---|
| Scene 1.1 | Distracted Study Session with Social Notifications |
| Scene 2 | Distracted in the Study Hall |
| Scene 3 | Thoughtful Pause in the Study Lounge |
| Scene 4.1 | More Living, Less Scrolling |
| Scene 5 | Focused Study in a Modern Library |
| Scene 6.1 | Digital Detox Week on Campus |

### 3. n8n Workflow Automation

Created an n8n workflow as part of the campaign system. The exported workflow JSON is included in this repository for technical reference.
